# Vantage — iPhone Simulator walkthrough

[Watch the 31-second film](vantage-demo.mp4) · [Animated preview](preview.gif) · [Poster](poster.jpg) · [Validation](validation.json)

A silent, 1920×1080 portrait screen recording of the real app on an **iPhone 17
Pro Simulator (iOS 26.5)**, placed inside a phone frame. The screen is live video
throughout. There are no titles, captions, side panels or screenshot sequences.

## Capture

- **Device:** iPhone 17 Pro Simulator, 1206×2622, iOS 26.5.
- **App:** the native Expo app from this repository. iOS uses
  `react-native-webgpu` 0.17.0 (Dawn/Metal, `three/webgpu`). Android keeps Expo
  GL with 2× render-target SSAA.
- **Driver:** `NativeShowcase.testShortVideo` in
  [`mobile/scripts/native-smoke/NativeShowcase.swift`](../mobile/scripts/native-smoke/NativeShowcase.swift).
  The test performs the taps, drags, tab changes and scrolling; the recording is
  the simulator display, not a generated animation.
- **Recording:** `xcrun simctl io <udid> recordVideo --codec=h264`.
- **Editing:** the raw take was trimmed from 17.5 s to 48.5 s (31 s), wrapped in a
  static phone bezel and rounded screen mask, with short fades. No app pixels were
  replaced, retimed or synthetically interpolated.
- **Onboarding:** this build has no onboarding or account flow. The film starts
  on the real Race screen rather than inventing one.

## Reproduce

Use the dedicated `Vantage Short Showcase` simulator or an equivalent iPhone 17
Pro Simulator. The app must be installed from the current build and the simulator
status bar can be pinned with `simctl status_bar` if desired. Run the commands
below from the repository root.

```sh
# 1. Generate and build the UI test project
ruby mobile/scripts/native-smoke/generate.rb /tmp/vantage-showcase-ui \
  "$(pwd)/mobile/scripts/native-smoke/NativeShowcase.swift"
xcodebuild build-for-testing -project /tmp/vantage-showcase-ui/NativeSmoke.xcodeproj \
  -scheme NativeSmoke -destination 'platform=iOS Simulator,id=<UDID>' \
  -derivedDataPath /tmp/vantage-showcase-ui/build CODE_SIGNING_ALLOWED=NO

# 2. Record while the test drives the app
xcrun simctl io <UDID> recordVideo --codec=h264 --force \
  mobile/build-logs/ios-showcase/short-raw-2.mp4
xcodebuild test-without-building -project /tmp/vantage-showcase-ui/NativeSmoke.xcodeproj \
  -scheme NativeSmoke -destination 'platform=iOS Simulator,id=<UDID>' \
  -derivedDataPath /tmp/vantage-showcase-ui/build \
  -only-testing:NativeSmoke/NativeShowcase/testShortVideo CODE_SIGNING_ALLOWED=NO
# Ctrl-C the recordVideo process when the test finishes.

# 3. Trim, frame and export the README media
python3 scripts/compose_ios_showcase.py
python3 scripts/make_readme_screenshots.py
```

Raw takes stay under `mobile/build-logs/` and are ignored. `Showcase/` contains
only the finished deliverables and provenance.

## Limits

This is a simulator capture, not a physical iPhone test. It does not establish
real-device GPU pacing, thermals, haptics, background recovery, VoiceOver,
dynamic type or sustained playback on hardware. The app remains a personal,
noncommercial evaluation build; the bundled OpenF1 data is not commercially
licensed. See [`../NATIVE-VALIDATION.md`](../NATIVE-VALIDATION.md).
